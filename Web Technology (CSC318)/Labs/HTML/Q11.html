Text Formatting Tags with Syntax and Usage

<b>Bold Text</b> → This text is bold.

<strong>Strong Text</strong> → This text is important.

<i>Italic Text</i> → This text is italicized.

<em>Emphasized Text</em> → This text is emphasized.

<u>Underlined Text</u> → This text is underlined.

<mark>Marked Text</mark> → This text is highlighted.

This is normal <small>small text</small>.

H2O → Uses <sub> for subscript.

X2 → Uses <sup> for superscript.

<del>Deleted Text</del> and <ins>Inserted Text</ins> are useful for revisions.
